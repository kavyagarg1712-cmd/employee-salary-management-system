# Employee Salary Management System

**Author:** Kavya Garg

A beginner-level C++ console project built to practice fundamental 
programming concepts.

## Features
- Add employee name and salary
- View all employee records
- Find the employee with the highest salary
- Calculate the average salary

## Concepts Used
- Arrays
- Loops (for, while)
- Functions
- If-else statements
- Switch-case
- Global variables

## What I Learned
While building this project, I learned how to store and manage 
data using arrays, write modular code using functions, and build 
a menu-driven program using switch-case.

## How to Run
1. Compile the code: `g++ filename.cpp -o output`
2. Run it: `./output`
